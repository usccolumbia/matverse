# Changelog

## 0.2.0 — 2026-11-01

Added a self-contained searchable HTML directory with combined filters, source details, URL state and filtered CSV/JSON exports. Added a generated root sources.md and source-link JSON covering 1,057 distinct URLs from the catalog and six requested collection/tool entrypoints, with inspection boundaries and adjacent resources labeled.

The catalog now has 145 dataset/release/subset records in 12 categories and 32 navigation resources. Added all 14 Starrydata project subsets and a 45-file row/size/SHA-256 manifest corroborated against provider release metadata. Added verified crystal-related records found through the new collections; unknown sizes and licenses remain explicit. Browser checks covered live search, filters, details, export and desktop/mobile layouts; 13 functional search/export tests were added.

## 0.1.0 — 2026-11-01

Initial MatVerse survey with 115 dataset/release records in 12 categories and 27 navigation resources. Added descending category tables, dataset evidence cards, a Scientific Data journal index, the requested ACS Perspective crosswalk, a narrative survey, machine-readable JSON/CSV, source/count receipts, and deterministic catalog validation.

Five sizes remain unverified and unranked. Counts are release-specific and heterogeneous; the catalog intentionally omits an additive total of materials. Reported licensing and access uncertainties remain explicit.
