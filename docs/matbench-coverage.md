Checked 2026-11-01. **All 46 displayed rows** agree with the maintained dataset registry at revision `8869a883a5067015b815886d878bd7aaa3862d2d` and are preserved as searchable source entries. All 126 distinct outgoing primary routes are included in the source inventory. The audit adds **13 named datasets/releases** and **8 resources**.

Before this audit, coverage included many major families but was incomplete at the named-release and subset level. The initial crosswalk found 23 rows with existing dataset-family mappings, two existing resources, thirteen missing named releases and eight missing adjacent/unreleased resources. A family match is not proof of an identical dated corpus or counting denominator.

## Coverage and counting boundaries

MP v2022.10.28 is a frozen historical release with 154,718 entries; it does not replace the current Materials Project card’s 271,325 structures. MatPES PBE and r2SCAN are separate 2025.1 releases. sAlex validation is a 553,218-frame subset that overlaps the existing train-plus-validation card. COSMOS aggregates many existing parents and cannot be added to them as a new population.

The page includes isolated molecules, molecular dynamics benchmarks, polymer data, software aggregators and unavailable full training corpora. These remain labeled resources or source leads. Public near-stable GNoME structures and the unavailable full GNoME training corpus have different scopes, as do public ELEMENTA partitions and the full training count.

Alexandria is an existing family match, not a verified exact match to the page’s 30,497,628-frame training corpus. The provider separates dated optimized-geometry and optimization-path downloads; the registry does not tie that count to one frozen path. Its page-reported count and links are retained below without overwriting the equilibrium-structure card or inventing a release boundary.

MDR-PBE has a documented 9,959-material reference claim but an independently counted current directory contains 9,958 mp-named files. The new card ranks the counted file population and preserves the discrepancy. PFT’s 8,510 training materials form an overlapping subset. None of these configuration, file, material and graph counts are interchangeable.

## Remaining release-level limits

- **GNoME:** The page counts an unavailable 89M-frame training corpus; the catalog contains the ~381k publicly released near-stable structures. These are related coverage, not the same release or denominator.
- **Alex:** The page describes an older ~30.5M-frame relaxation corpus; the existing Alexandria card describes a newer ~5.8M equilibrium-structure release. Related family, not identical count scope.
- **sAlex:** Existing card counts train+validation together (11,000,983), while the page sAlex row counts only 10,447,765 training frames. Validation is now separately cataloged as an overlapping subset.
- **OpenLAM:** Existing training-set card is unranked. The benchmark reports 162,507,178 configurations across 31 parents; retain as a benchmark-reported size rather than silently replacing unverified release counts.
- **ELEMENTA:** The page reports the full 210,656,285-frame corpus, including unavailable frames; catalog cards cover the ~39M public core and separate ~4.7M Spin releases. Not identical release scope.
- **OCx24:** The page materials count is 19,406 deduplicated computational candidates; the existing experimental card counts 5,412 rows of measurements. Both concern one project, but neither denominator is a number of independent crystal structures.
- **AFLOW:** Repository counts evolve; the page snapshot does not overwrite the newer or differently scoped catalog count.
- **OQMD:** The page uses OQMD v1.6 (November 2023); preserve current catalog version/count separately.
- **OMat24:** The page reports 100,824,585 training configurations. Validation is a separate download with corrected December2024 files; do not infer a full release count from the training-only row.
- **QMOF:** The page snapshot counts20,372 qmof_id records, whereas the existing catalog release may use a different archive/snapshot. Preserve version distinctions.
- **MAD-1.6:** The page exact362,646 total is a benchmark recount of specified r2SCAN split files; existing card remains separately versioned and unranked until those payloads are independently checked here.
- **MatterSim:** Training data remain unreleased; public code/checkpoints do not establish data access.
- **NOMAD:** Represented as a repository/discovery resource rather than a fixed additional crystal corpus.
- **MatPES licensing:** Primary current Hugging Face data card declares BSD-3-Clause whereas Matbench metadata lists MIT. New frozen2025.1 cards retain this mismatch; data-license verification remains unresolved.
