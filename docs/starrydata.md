## File-level provenance

All **45 CSV.gz download files** (three full files and three per project) have recorded URLs, row counts, byte lengths and SHA-256 values in [data/starrydata_files.json](../data/starrydata_files.json). The size/hash values agree between the provider manifest and GitHub release asset metadata. This is a metadata cross-check, not an independent recount of the full CSV payloads.

The `latest` release tag is mutable. Check a downloaded file against the saved hash before treating it as this snapshot. The original provider page also links its latest-data Google Drive mirror and monthly Figshare archive; use that page for current mirror links.

## Data and reuse cautions

- Samples are literature samples, not unique compositions or atom-resolved crystal structures. Curves contain multiple points.
- Full and per-project paper tables have different scopes; some source papers have no digitized data.
- The provider reports sample-ID collisions in some April–September 2026 releases; inspect its changelog and preserve `(SID, sample_id)` joins where needed.
- The 2026-11-01 archival metadata declare CC BY 4.0; cite Starrydata and the original publications when using observations.
