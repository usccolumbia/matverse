# OpenAlex specialized-property dataset search

Date: 2026-11-01. Local-only: no GitHub publication authorized.

RQ1: Which paper-backed specialized property datasets complement the existing crystal-materials catalog, starting from DDSE solid electrolytes?
RQ2: Which releases supply experimental measurements, computed properties, atomic structures or only compositions, and what exactly do their counts measure?
RQ3: What access, reuse, version and source-lineage limits matter when combining these datasets?

Audience: materials informatics researchers and software agents. Coverage axes: electrochemical transport/electrodes; ferroic/dielectric/electronic/optical; thermal/magnetic/mechanical; supplementary chemical stability/storage searches. Relevance is an evidence/scoping decision, not a citation-count ranking. Date-unrestricted OpenAlex searches and DDSE citation/reference traversal supply candidates; primary sources verify promoted data. Existing catalog records are crosschecked before additions.

API query caps and outcomes are retained per query; this is a broad reproducible search, not proof of exhaustive coverage. OpenAlex is queried automatically. Primary publisher/provider/repository pages verify records. Crossref and Semantic Scholar are not additional systematic search corpora. CNKI/Wanfang are not covered. 英文库没检索到 ≠ 没人研究过.
