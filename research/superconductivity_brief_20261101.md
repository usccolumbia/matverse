# Superconductivity coverage supplement

Date: 2026-11-01. Audience: researchers choosing public crystal/materials datasets through MatVerse.

1. Which experimental, structure-linked, electronic-structure and computational electron–phonon superconductivity datasets are publicly documented, including Richard G. Hennig group's releases and all user-named sources?
2. What exactly does each size count, which properties and structures are available, and which labels are experimental, DFT-derived or machine-learning predictions? What pressure, lineage, access and license limits affect reuse?
3. Why does a search for “superconductor” miss 3DSC, and how can the interface reveal relevant datasets when the user is browsing a filtered source collection?

Three independent retrieval perspectives cover the Hennig-group literature, the user-listed experimental/public resources, and specialized datasets plus an audit of existing entries. Root work handles retrieval integration, UI behavior, reproducible regression tests and publication.

Only documented releases enter the ranked catalog. Dataset counts retain their units and overlap caveats; inaccessible resources and navigation pages receive explicit availability descriptions. A thematic comparison will distinguish these evidence types rather than total their record counts.
