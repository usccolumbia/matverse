## Brief and search coverage

RQ1: Which Scientific Data releases add missing materials characterization or composition–processing–microstructure evidence? RQ2: What do their published sizes actually count, which conditions and structural representations are available, and what dataset rights are verified? RQ3: Which papers repeat an existing release, describe a schema without an independently verified corpus, or concern adjacent biological/geophysical/engineering data?

The deep-research workflow was applied through independent search perspectives: microscopy and microstructure, diffraction and computed spectral references, correlative measurement and deformation, and synthesis/processing provenance. Searches targeted primary Scientific Data pages across legacy and modern DOI formats. The parent's complete journal corpus (`journal_works.json`, 9,304 works) and broadened candidate subset were also scanned for characterization terms and blind spots. All 25 selected paper DOIs were matched against that full corpus. This perspective did not call OpenAlex bulk APIs.

Primary publisher full text, author deposits and depositor metadata were inspected. Figshare and Zenodo APIs established dataset-specific versions, file presence and licenses; Materials Cloud landing pages supplied rights and file inventories; Dryad metadata established CC0 licensing. Registered Science Data Bank metadata identified SIMPOD V4 and CC0 rights. The publisher article license was never substituted for external data rights. Raw HTML, JSON and selected dataset indices were saved only under ignored `research/cache/sdata_characterization/`; compact task receipts preserve URLs, versions, rights, file examples and hashes.

The Obsidian core memory notes and relevant AI-datasets project note had already been read in this session. Their provenance and condition-separation preferences were applied. No new memory entry was required for this research-only package.

## Main findings and comparison

The largest new experimental cohort is JCAP's 179,072 metal-oxide samples with composition, processing history, RGB images and UV–Vis measurements. It is distinct from HTEM. Its 180,902 HDF5 rows include 1,830 blank substrate references, and the paper reports 99,965 unique intended metal compositions. Intended metal fractions are not measured oxygen stoichiometry or resolved crystal structures.

SIMPOD contributes 467,861 COD-derived structure/pattern pairs under CC0. It is structurally linked simulated powder diffraction, while existing opXRD is an experimental diffraction collection. SIMPOD preserves atomic numbers/positions, occupancies, cell and space group, but omits original author/publication metadata from its simplified records. Recover parent provenance through COD identifiers. Its idealized Cu-source patterns have fixed widths and no background; they do not represent experimental diffraction noise.

The computed spectroscopy additions include MP K-edge XANES (>500,000 site spectra), MP L-edge XANES (~140,000 site/edge spectra), 2,681 sulfur K-edge spectra for 66 lithium-thiophosphate models, four independent Raman releases, JARVIS-STM's 716-material cohort and 10,023 inorganic crystal models with synthetic INS spectra. These are additional property releases over parent MP/JARVIS/PhononDB/2DMatPedia/ICSD structures, not independent universes of new material identities. The INS record deliberately excludes the separate gas-phase molecule cohort in the same deposit.

Raman releases differ in calculation approach and parent structures: the 2019 MP cohort contains 55 compounds and a RRUFF-matched validation table; Oulu's release has 5,099 completed materials and reuses PhononDB modes; the hybrid-functional release describes 161 inorganic compounds from ICSD; the 2D release adds spectra for 3,504 2DMatPedia monolayers. Differences in functional, resonance approximation, dimensionality, normalization and broadening must remain with the values. RRUFF-derived reference peaks are not new independent measurements.

Experimental reference data include ten battery-interphase compounds with IR/Raman/XRD collected under inert conditions, five STEM tomography material systems, the Aachen-Heerlen steel image family, Pd-on-carbon ordering images, AmalgaMatch's 187 correspondence-annotated image pairs and a molecular-salt morphology benchmark. Microscopy pixels, tomographic voxels, grain orientations and material labels are distinct from periodic atom coordinates. The schema's `mixed` or `composition_only` values are conservative placeholders for these microstructural representations; caveats explicitly state their limits.

The correlative Inconel 718 release links surface/3D EBSD, HR-DIC deformation fields and meshed grain structure. Its independent-specimen count was left null rather than using slices, voxels or download files as material counts. The ferritic-steel XCT release instead supplies an explicit 276 sample-condition datasets, covering one alloy under different tensile/fatigue states. FatigueData-AM2022 adds 2,460 test-condition curve datasets for 116 AM alloy types. It is a separate sibling of already cataloged FatigueData-CMA2022, with potentially overlapping source experiments.

Processing evidence includes FePTP's 11,241 iron-phase transformation pathways and the early 30-system oxide synthesis-parameter aggregate (merged with the property agent during parent integration). FePTP retains unchanged outcomes and contains environmental/biotransformation pathways, so a crystal-materials subset must be selected. The early oxide resource is a distribution/co-occurrence aggregate, not 30 individual recipes and not equivalent to the later procedure-level synthesis corpora already in MatVerse.

## Evidence limits that must survive integration

- Aachen-Heerlen releases 2,580 image cases, with polygon annotations on only 1,705. TIFF/PNG equivalents must not be counted twice. Specific compositions are withheld; composition classes and heat-treatment conditions are supplied.
- The ferritic-steel descriptor's headline 134 tensile plus 142 fatigue datasets gives 276, but some fatigue subgroup figures elsewhere do not reconcile directly with 142. The record preserves the headline cohort and notes the discrepancy. Raw XCT voxel size is 3 µm, whereas fatigue quantification used downscaled 12 µm data.
- XANES site spectra, edge spectra, structure/element averaged spectra and unique crystal identities are different counting units. In particular, the L-edge release's 40,000 site-averaged counts are not 40,000 unique crystals.
- MicroLib is a generated microstructure resource and includes biological/noncrystalline materials. Its Zenodo metadata declares open access but does not contain a license field; the record explicitly says unknown. Do not infer a CC license from the article.
- The lithium-thiophosphate spectral cohort mixes 18 crystalline and 48 amorphous models. The QPS morphology images also mix crystalline/amorphous solids and include foil controls. Preserve material state and controls.
- For BraggNN, a named public HDF5 benchmark family and fitted peak-coordinate semantics are verified, but the independent record count and dataset license remain unknown. Bulk access was not exercised. GPU-serving group authorization is separate from dataset rights.
- For multi-deposit resources such as STEM tomography and zeolite synchrotron imaging, only sampled/core item rights were directly checked. The catalog license string records that scope rather than applying an unverified blanket license.
- Dryad public API metadata currently gives submitted-version status for several records. The staged scientific counts refer to published descriptor cohorts, not assumed new draft versions.
- Whole multi-gigabyte archives were not downloaded. Published cohort counts are labeled accordingly; a small INS crystal index was fetched separately as a lightweight check. This is not full dataset or scientific reproduction validation.

## Deferred and excluded directions

Named leads preserve NFFA's overlapping SEM subsets, Ti-7Al topotomography, RefXAS curation, gold-nanoparticle synthesis, photoemission workflows, core-shell XFEL diffraction, wire-arc/DED process imaging, melt-pool imagery and aluminium crack-growth DIC. They need independent deposit checks, clearer material-property links or scope decisions. NFFA's tested legacy B2SHARE API returned 404, although its original descriptor and DOI lineage are real.

Pure biological microscopy and medical imaging were excluded, as were reservoir-rock/geospatial datasets and predominantly polymer-waste identification resources under this task's crystal-materials scope. Atom-probe searches did not produce a fully verified, in-scope independent Scientific Data release; this is a search limitation rather than a claim that no such data exist. The bulk agent covers Cu grain-boundary and Ti/Ti64 atomistic data; the property agent covers Al-alloy patent data, LPBF density, elastic moduli, sol-gel purity and Trace-IN625.

All source IDs and dispositions remain available for targeted follow-up. `receipt.json` records schema checks, collisions, DOI matching and hashes. No candidate counts should be added to a global unique-crystal total without matching parent IDs, sample/processing state and measurement conditions.
