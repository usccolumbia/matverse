# Attached Data.gov metrology candidates: verified selection

Checked 2026-11-01. This is the assigned 13 attached occurrences (7 distinct literal titles), not a general search for unrelated datasets. Four independent releases are staged in `additions.json`; two adjacent resources in `resources.json`; every assigned occurrence is retained verbatim in `leads.json`. Canonical data files, scripts, UI and Git state were not edited.

## Overlap and count decisions

CAMEO is a proven duplicate of existing REMI; no aggregate count was added. Zn–Sn–Ti–O is a study about the HTE Materials Collaboratory, with registry-dependent analysis code; do not silently treat it as a new corpus independent of HTEM. The four selected releases are not JARVIS releases, and their source experiments/models have different identities and conditions. The RP computed CIFs are supporting models and are not counted as measured experimental material samples. The USGS legacy total of 169 belongs to the 2003 collection: this downloaded 2021 table actually has 156 reference patterns.

NIST license fields above are based on each current release's explicit `license` declaration plus its README/data-use notes. They are **not** a claim that every government-hosted object is automatically public domain or CC licensed. The RP README additionally separates article-content rights from data-use permission. Neither short dataset documentation nor an error column alone establishes a fully certified uncertainty budget.

## Verification artifacts

- `receipts.json`: 83 compact fetch/verification receipts, including original failed URLs. Some successful downloads' compact receipts were reconstructed from the retained file and confirmed HTTP-200 output; those timestamp bases are labelled explicitly.
- `payload_verification.json`: 35 payload-versus-provider SHA-256 matches and four byte-identical CAMEO/REMI array comparisons.
- Raw catalog HTML, NIST primary JSON responses, repository responses and selected payloads are only under ignored `research/cache/datagov_20261101/metrology/`. Files named `*_landing.html` are actually the primary NIST JSON metadata response; the suffix is only a local acquisition label.
- JSON syntax, four new IDs against existing canonical IDs, and coverage of all 13 assigned ranks were checked. No numerical measurement replication was performed.

The primary NIST responses matter: Data.gov may preserve stale download names, old dates or an older version label. For example, the Zn–Sn–Ti–O current analysis archive was discoverable only from current primary metadata, and the hafnia current version changed collection membership without changing its initial-release README. Public landing pages were sufficient for this verification; no credentials or access-bearing URL values were stored.
