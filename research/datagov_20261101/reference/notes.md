# Attached Data.gov reference-property selection

Verified 2026-11-01. Scope: six title families at 12 attached ranks, not a new search beyond those entries. No matching MatVerse project note exists in the Obsidian Projects index; core vault preferences were read. Canonical data, scripts, UI and Git were not changed.

## Selection judgment

**SRD81 is the strongest reusable dataset in this group.** A documented public JSON endpoint returned 2,175 objects with 2,175 unique database IDs. This is a measurement count, not a distinct-material count; the separate material-name lookup has 108 categories, which must not replace that count. The interface documents specimen identity and geometry, thermal boundary conditions, apparatus and test method, conditioning and moisture fields, and uncertainty conventions. However, 1,667 measurement objects have null uncertainty. The source's typical uncertainty guidance is not per-row experimental uncertainty. The API has bare numeric field names and apparently uses inch-pound values; an extraction pipeline must resolve units against the interface before merging these data. It is a historical reference: actual data last updated 1983, web version 2.0 released December 2015. The attachment's January 2000 timestamp is the old web release, not a current data release. Sources: [API](https://srdata.nist.gov/insulation/api/TableAllData), [definitions](https://srdata.nist.gov/insulation/Home/DataFieldDef), [version history](https://srdata.nist.gov/insulation/Home/VersionHistory).

**Cryogenic Materials is useful as an unranked correlation dataset.** The official relocation notice points to TRC; the live 6061-T6 aluminum page exposes equations and coefficients, units, data and equation temperature ranges, and fit-error values. Those errors describe correlation agreement with data, not full measurement uncertainty. A source bibliography is available. The regenerator endpoint returns a spreadsheet-style HTML numerical table, rather than a verified XLS/CSV download. No complete measurement/material count or uniform release was established. Keep the correlation nature explicit; do not generate many temperature-grid points and call them independent measured records. Sources: [relocation](https://www.nist.gov/mml/acmd/nist-cryogenic-materials-property-database-index), [6061-T6 example](https://trc.nist.gov/cryogenics/materials/6061%20Aluminum/6061_T6Aluminum_rev.htm), [bibliography](https://trc.nist.gov/cryogenics/materials/references.htm).

**Structural Ceramics SRD30 is useful as an unranked evaluated-property dataset, with less convenient access.** Current search and citation records work. The sampled corundum citation includes processing, material identity, calorimetry descriptions, units, uncertainty estimates and property-specific evaluation. Evaluation status is heterogeneous even within one record: its heat-capacity table is evaluated, while grain size is unevaluated. No verified bulk structured export or collection cardinality was found; repeated citation links in search results are not a material count. Actual data content was last updated 2002, not the catalog's 2015 timestamp. Sources: [database](https://srdata.nist.gov/CeramicDataPortal/scd), [sample numerical record](https://srdata.nist.gov/CeramicDataPortal/Scd/Y00001).

## Resources rather than new independent ranked datasets

- **Sandia Hydrogen Compatibility (rank 10):** valuable handbook chapters with source literature and individual revision labels, plus a live downloadable 2012 archival report. Chapters/files are not material records. The complementary structured database page currently says it is under construction, with a new Granta MI link planned for Fall 2026; no working present bulk data release was verified. Keep as a reference resource. [Primary collection](https://www.sandia.gov/matlstechref/), [current database status](https://www.sandia.gov/matlstechref/hydrogen-materials-technical-database/).
- **SRD150 Property Summaries (58,59):** high scientific reference value but derived summaries overlap SRD30 and linked topical databases. The alumina example identifies a narrow purity/density/grain-size scope, temperatures, units and combined standard uncertainty notation. These are not newly independent specimen measurements, nor are all portal values universally validated. Keep as a reference resource. [Summary](https://srdata.nist.gov/CeramicDataPortal/Pds/Scdaos).
- **ACerS-NIST SRD31 (230,231):** current v6.0 (2025) has expert critical evaluations and 34,000 phase diagrams, but paid full products/online subscription. Joint copyright and product access distinguish it from a free data release. Diagram totals do not count unique materials. Free PED Editor is software, not a free copy of the full database. [Current primary product](https://www.nist.gov/srd/nist-standard-reference-database-31).

## Rights, verification limits and evidence

Public retrieval was checked separately from data reuse terms. SRD81 and the Ceramics Data Portal assert copyright/all rights reserved; this is not an open data license. No collection-specific open license was verified for the Cryogenic collection or Sandia reference. No government-wide public-domain or website license was substituted for data rights. These limitations are carried in staged records.

Quality ordering reflects the evidence of reusable measurements, schema/units/conditions and provenance, not agency name, catalog search rank or download size. Verification samples numerical payloads and documentation; it does not independently reproduce measurement values, uncertainty calculations, or every record in the legacy collections. Three dataset records (one with a qualified measurement count, two null/unranked) and three resources are staged; integration remains the parent task's choice.

`receipts.json` records requested/final public URLs, fetch timestamps, HTTP status, content types, byte sizes and SHA-256 hashes. Raw pages, API payloads and PDF are only in ignored `research/cache/datagov_20261101/reference/`. `validation.json` records exact JSON counts and successful canonical-schema validation. `leads.json` preserves all six literal titles and all 12 attached occurrences, including duplicates across catalog agencies.
