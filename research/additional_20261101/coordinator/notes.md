# Coordinating search: atomistic references and experimental properties

Completed locally on 2026-11-01. Sixteen complete records are staged in additions.json. Primary provider pages, author repositories, publication metadata and named dataset deposits were inspected; complete API/HTML bodies and payloads remain only in ignored research/cache/additional_20261101/coordinator/. Compact response receipts and count receipts identify exact source URLs, statuses, byte counts and hashes.

## Findings and comparison

SoLiD26 is now openly released in Materials Cloud (2026.189 v1, 2026-10-13), with 15,379,823 configurations and CC BY 4.0. The September preprint's by-request statement is superseded by its October v2 and the actual deposit. Sixteen compressed ASE-LMDB shards and the public README/checksums were inspected; the 63.8 GiB payload was not downloaded. Source-stated ASE constraint handling matters: use raw forces, rather than inadvertently applying fixed-atom masks.

The SevenNet-Omni domain-bridging set adds about 125,000 new DFT labels on sampled parent geometries. The count deliberately excludes the hundreds of millions of entries in its aggregate training collection and does not count the model checkpoint as a dataset. Molecules, crystals, surfaces and MOFs are mixed; parent overlap remains explicit.

SACADA's live public table contains 1,661 unique IDs, independently counted from its read-only public endpoint exposed by the site HTML. The site's displayed update date remains 2024-02-15; this is not asserted as the actual update time of all current rows. A sample structure ZIP contains both optimized and ideal-net CIFs, counted once as one table entry. Rights and complete coordinate coverage remain unverified.

The carbon GAP-20 and GAP-20U corpora are related releases with different sizes, labels and licenses. The revised complete gzipped extXYZ was independently parsed: 6,088 frames, 400,275 atoms. Six named Si/SiO2/GST/P/graphene-oxide/SiOx reference cohorts use load-atoms' explicit normalized counts and independently verified original deposits. They are smaller fitting/reference populations, not every file in the source archives. GST selects the PBE cohort, and SiOx includes parent Si-GAP/SiO2-GAP records. Original and normalized distribution terms must remain distinguished, particularly Si and amorphous graphene.

Two synthetic structural benchmarks add a 3,069-model amorphous/paracrystalline silicon collection and a 150-configuration amorphous-graphene subset. Their energy/force labels come from trained potentials; they are not independent DFT evaluations of every record. The existing carbon-data-gap17 record already represents the C-SYNTH-23M lineage, so that name was not added as a duplicate corpus.

The current sysTEm workbook has 8,650 nonempty rows/unique row IDs, 1,437 standardized composition strings and temperatures 10–1275 K. It merges extended MRL and ESTM observations; these populations are not additive. Its zT consistency tolerance is a curation rule, not independent validation of experiments. The complex-oxide CTE workbook has 204 rows with composition, coefficient, temperature interval and source fields. Both repositories declare MIT; record source-paper and parent-data lineage when reusing.

ULTERA's May 2025 alpha record describes 12,540+ experimental HEA/MEA property observations and 4,270+ materials, with 813 source publications. Its files are restricted and the metadata has no data license. No request or message was sent to the authors. The lower-entropy-inclusive count is a separate denominator, not a larger independent HEA population.

## Evidence limitations and unresolved leads

Public documentation verification is not full row-level scientific replication. Only selected small files were independently counted; explicit documentation counts remain labeled as such. Several Crossref probes returned HTTP 429; failed probes are retained and not represented as successes. Verified provider deposits, author citations and available papers support the promoted records. No external source code or pickle was executed.

The current MatPES v2025.2 release is an existing-family version lead rather than a separate independent corpus. The AFLOW thermal-expansion Foundry mirror overlaps AFLOW thermomechanical data already represented. Additional metal-oxide potential and high-pressure neutron references remain deferred; their existence alone did not establish a normalized independent release count and full rights. This is a targeted extension across missing domains, not a census of every materials dataset online.
